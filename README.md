# 💖 Digital Gift Memory Journey Website

A romantic, interactive digital gift website designed as a surprise memory journey for your girlfriend.

## 📁 File Structure

- `index.html`: Contains all 8 romantic sections.
- `style.css`: Dark velvet rose glassmorphism styling, responsive layouts, 3D envelope effects.
- `script.js`: Interactive animations, typing FX, envelope letter typewriter, quiz game, proposal fireworks, particle canvas.
- `images/`: High quality sample romantic photos (`memory1.jpg` to `memory6.jpg` and `photo1.jpg` to `photo6.jpg`).
- `music/`: Audio directory containing `INSTRUMENTAL-CKay-Love-Nwantiti-Ah-Ah-Ah-Prod.-KG-Beatz-via-instrumentals.com_.ng_.mp3` (also mirrored to `love-song.mp3`).

## 🛠️ How to Customize

1. **Title & Girlfriend's Name**: Edit `ROMANTIC_CONFIG.typingTitleText` in `script.js`.
2. **Love Letter**: Edit `ROMANTIC_CONFIG.letterMessage` in `script.js`.
3. **Memories & Dates**: Edit text and images in `index.html`.
4. **Quiz Questions**: Edit `ROMANTIC_CONFIG.quizQuestions` in `script.js`.
5. **Background Music**: Replace the track in `music/` or edit `ROMANTIC_CONFIG.musicTrack` in `script.js`.
